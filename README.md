# Flappy Bird Neon

A modern neon-themed **Flappy Bird** web game built using **HTML, CSS, and JavaScript**. This project reimagines the classic arcade game with glowing visuals, responsive gameplay, smooth animations, and multiple difficulty levels for a modern browser experience.

# Features

- Modern neon-themed UI
- Classic Flappy Bird gameplay
- Multiple difficulty levels
- Distance tracker
- Score tracking
- Responsive design
- Mobile-friendly controls
- Smooth animations
- Glowing visual effects
- Pause functionality
- Lightweight and fast
- Runs entirely in the browser

---

# Mobile Support

The game is fully playable on both desktop and mobile devices.

Desktop players can use the keyboard, while mobile users can simply tap the screen to control the bird, providing a smooth and intuitive gameplay experience.

# Gameplay

1. Start the game.
2. Tap or press Space to make the bird fly.
3. Pass through the obstacles.
4. Increase your score and travel farther.
5. Challenge yourself with higher difficulty levels.

---

# Controls

## Desktop

- **Space** — Fly
- **P** — Pause

## Mobile

- Tap anywhere on the screen to fly

